# CodeAlpha_Sentiment_Analysis
Sentiment Analysis using NLP to classify Amazon customer reviews into Positive, Negative, and Neutral sentiments with emotion detection.
📊 Sentiment Analysis using NLP

This project performs Sentiment Analysis on Amazon customer reviews using Natural Language Processing (NLP). Reviews are classified into Positive, Negative, and Neutral sentiments, along with basic emotion detection.

🎯 Objectives
Analyze Amazon customer reviews
Clean and preprocess text data
Classify reviews as Positive, Negative, or Neutral
Detect customer emotions
Visualize sentiment patterns
Generate useful business insights
